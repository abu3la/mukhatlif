# تحميل واجهات الموقع

استبدلت رسائل انتظار المحتوى الظاهرة بهياكل Skeleton للأغلفة والأسطر والحقول. حالة الانتظار النصية مختصرة ومخفية بصريا لقارئ الشاشة فقط. حالات الخطأ والفراغ وإجراءات الأزرار ليست Skeleton.

| المفتاح | النص الحالي | يبقى / يحذف | البديل |
|---|---|---|---|
| LoadingRegion | جار التحميل وما يماثلها في صفحات البرامج والمقالات والحلقات والضيوف | يحذف بصريا | هيكل القائمة؛ وصف مختصر لقارئ الشاشة |
| CustomerGate | جار تحميل حسابك | يحذف بصريا | هيكل حقول الحساب |
| CustomerEpisodeList / ContinueListening | جار تحميل الحلقات / المكتبة | يحذف بصريا | أغلفة صغيرة وأسطر عناوين وبيانات |
| Library / onboarding | جار تحميل البرامج والقراءات ونتائج البحث | يحذف بصريا | بطاقات البرامج أو صفوف المحتوى |
| EpisodeMoments / queue | جار تحميل اللحظات / قائمة الانتظار | يحذف بصريا | صفوف مؤقتة؛ تبقى بيانات قائمة الانتظار الموجودة عند التحديث |
| guest loading intro | ننتقي ضيوفنا لنثري الحوار | يحذف | عنوان ضيوفنا وهيكل بطاقات الضيوف |

ستة قرارات حذف للنص المرئي، مع إبقاء وصف التحميل لقارئ الشاشة في المجموعات الخمس الأولى. أضيف loading.tsx عام للمسارات التي لا تملك حالة تحميل خاصة. لم يتغير تأكيد الحساب أو إرسال النماذج أو تشغيل الصوت.

التحقق: 198 اختبارا ناجحا، وTypeScript وESLint. معاينة المكون الفعلي داخل تصميم الموقع على سطح المكتب وعلى 390×844؛ عرض المستند وعرض التمرير كلاهما 390px. أشكال الجوال في عمودين، بلا قص للنصوص أو عناصر تفاعلية وهمية. تحترم الحركة تقليل الحركة، والمحتوى الحقيقي لا يعتمد على اكتمال حركة لظهوره. أزيل مسار المعاينة المؤقت. التعديل محلي ولم يدمج أو ينشر.
