# مؤشر التنفيذ داخل الأزرار

هذا التوجيه يحل محل تعميم حذف «جار» في مراجعات النصوص السابقة: رسائل الانتظار خارج الأزرار تراجع بحسب السياق. داخل الزر يستبدل النص بصريا بمؤشر دائري أثناء تنفيذ الإجراء، مع إبقاء الاسم الأصلي لقارئ الشاشة.

مكون Button المشترك يستجيب إلى aria-busy، ويمنع النقر المتكرر، ويحتفظ بمساحة النص حتى لا يتغير حجم الزر. لا تعني disabled وحدها وجود عملية تحميل. المؤشر يتوسط الزر، ويستخدم لون النص، ويتوقف دورانه عند تفضيل تقليل الحركة. عند انتهاء العملية أو فشلها تعود التسمية العادية بحسب حالة الصفحة.

ربطت حالات الحفظ والدخول والخروج والإضافة والإزالة والتنزيل والتحديث والتصدير والتحقق ورفع الصور. تظل نسب رفع الملفات وأخطاؤها ظاهرة خارج الأزرار. لم تتغير آليات الحفظ أو النشر أو الاتصال.

المعاينة استخدمت نفس المكون ونفس CSS في صفحة محلية مؤقتة بعملية معلقة لمدة محددة. نقرة فعلية أظهرت المؤشر الدائري؛ أبعاد الزر قبل التنفيذ وأثناءه وبعده 123.984375 × 42 px، وانحراف مركز المؤشر أقل من 0.001 px. الزر المجاور معطل دون مؤشر، وبعد الاكتمال اختفى المؤشر وعاد الزر متاحا. أزيلت صفحة المعاينة المؤقتة.

أضيفت اختبارات للمكون تتحقق من منع تكرار النقر، وثبات الاسم المتاح لقارئ الشاشة، واستعادة الإجراء، والتمييز بين التعطيل والتحميل. فحص TypeScript وESLint ناجحان. التعديلات محلية ولم تنشر.
