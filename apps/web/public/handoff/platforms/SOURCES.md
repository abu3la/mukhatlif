# Listening platform marks

Retrieved/extracted 2026-09-05. All three are existing brand assets; no icon geometry was drawn or approximated for this project. Fill is set to `#171a56`; no enclosing UI tile or background was added.

## YouTube and Spotify

- Files: `youtube.svg`, `spotify.svg`.
- Immediate source: the official Mukhtalif homepage saved as `research/home.html`, lines 430 and 414 respectively. Paths and viewBoxes are preserved verbatim. Removed source-specific CSS classes and `aria-hidden`; added accessible titles, image roles and the shared fill.
- Original publisher of icon geometry: Font Awesome Brands (the site's stylesheet identifies Font Awesome 5.15.3).
- Source homepage: https://mukhtalif.net/
- Upstream icons: https://github.com/FortAwesome/Font-Awesome/blob/5.15.3/svgs/brands/youtube.svg and https://github.com/FortAwesome/Font-Awesome/blob/5.15.3/svgs/brands/spotify.svg

## Apple Podcasts

- File: `apple-podcasts.svg`.
- Retrieved directly from the official Simple Icons repository: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/applepodcasts.svg
- Browseable source: https://github.com/simple-icons/simple-icons/blob/develop/icons/applepodcasts.svg
- Upstream metadata: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/data/simple-icons.json ; Apple Podcasts entry cites Apple's identity-guideline page: https://www.apple.com/itunes/marketing-on-podcasts/identity-guidelines.html#apple-podcasts-icon . The metadata was retrieved in this run; Apple's page itself was not inspected.
- Geometry and `viewBox="0 0 24 24"` preserved verbatim. Only `fill="#171a56"` added.
- License: Simple Icons CC0 1.0 Universal, https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md and https://creativecommons.org/publicdomain/zero/1.0/ . Trademark rights remain with their respective owners.
- Geometry caveat: this authentic Simple Icons asset includes the rounded-square application silhouette within its compound path. That silhouette is part of the supplied artwork, not a decorative container added by this project. It has not been cut away or redrawn to imitate a standalone central glyph. A requirement to remove that built-in silhouette would need a different official standalone asset.
